### 🔬 Featured Project

#### 🤖 [Autonomous Social Media Strategist](https://github.com/makarand-thorat/AI-Engineering-Sprint)
> Multi-agent content pipeline powered by LangGraph, Gemini 1.5 Pro & LangSmith

- **Multi-Agent Orchestration** — LangGraph stateful graph with specialised agent nodes for research, drafting, and critique
- **ReAct + Live Search** — DuckDuckGo API integration grounds the agent in real-time 2026 data, eliminating hallucinations
- **Self-Correction Loop** — Critic Node audits drafts against brand guidelines and triggers recursive rewrites via feedback cycles
- **Human-in-the-Loop (HITL)** — Async approval workflows with state persistence and checkpointing
- **LLMOps** — LangSmith traces agent trajectories, identifies bottlenecks, and evaluates output quality
- **Production Deployment** — LangServe + FastAPI REST endpoints for seamless frontend integration
